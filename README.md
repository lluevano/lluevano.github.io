# lluevano.github.io

Personal academic website of Luis S. Luévano, Assistant Professor at the Universitat Autònoma de Barcelona (UAB): <https://lluevano.github.io>

Built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, a fork of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme (MIT License, see `LICENSE`).

## Structure

- `_pages/`: main pages (about, CV, publications, talks, teaching, news archive)
- `_publications/`, `_talks/`, `_teaching/`, `_portfolio/`, `_posts/`: content collections
- `files/`: papers, posters and slides served at `/files/...`
- `images/`: logos, profile photo and figures

## Run locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```
